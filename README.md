🎬 Movie Mikey

Movie Mikey is a sleek and responsive movie and TV series discovery web application built with React.js, Vite, and the TMDB API. Users can explore popular, trending, upcoming, and top-rated movies and TV series with a modern, user-friendly interface.

🚀 Features
🌍 Home Page with Featured Content

🎥 Movies Section (Now Playing, Popular, Top Rated, Upcoming)

📺 TV Series Section (Airing Today, Popular, Top Rated)

🔍 Search Functionality for Movies and TV Shows

📄 Detailed View Pages for Movies and TV Series

🌐 Client-side Routing using React Router

🔄 Scroll to Top on Route Change

📱 Fully responsive UI

🛠️ Tech Stack
Frontend: React.js, Vite

Styling: CSS (with custom scrollbar styling)

Routing: React Router DOM

API: TMDB (The Movie Database) API

Deployment: Docker-ready configuration
